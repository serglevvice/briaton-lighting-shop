# 💡 Briaton — Интернет-магазин осветительного оборудования

Интерактивный каталог интернет-магазина светильников и люстр **Briaton**. Проект разработан на чистом JavaScript (ES6+) с использованием модульной архитектуры, асинхронной подгрузки данных и сторонних UI-библиотек.

🔗 **[Посмотреть живое демо (GitHub Pages)](https://serglevvice.github.io/briaton-lighting-shop/)**

---

## 🚀 Реализованный функционал

- **Динамический каталог товаров:** Асинхронная загрузка данных из JSON (`fetch`, `async/await`) с обработкой сетевых ошибок (`try/catch`) и генерацией карточек в DOM.
- **Комплексная фильтрация:**
  - Фильтрация по нескольким категориям одновременно (подвесные, потолочные, накладные, точечные, ночники).
  - Автоматический подсчет количества доступных товаров для каждой категории при инициализации.
  - Фильтрация по статусу наличия товара («В наличии» во всех городах / «Все»).
  - Сброс фильтров к исходному состоянию.
- **Сортировка:** Динамическая сортировка отфильтрованных товаров по возрастанию цены, убыванию цены и популярности (рейтингу).
- **Пагинация:** Разбивка каталога по 6 товаров на страницу с автоматическим пересчетом количества страниц при изменении фильтров.
- **Корзина покупателя с сохранением состояния:**
  - Добавление товаров как из основного каталога, так и из блока «Товары дня».
  - Удаление позиций и динамический пересчет счетчика товаров в шапке.
  - Синхронизация с **`localStorage`** — содержимое корзины сохраняется при перезагрузке страницы.
- **Слайдер «Товары дня»:** Карусель акционных товаров (`goodsOfDay`), реализованная с помощью библиотеки **Swiper.js**.
- **Интерактивные тултипы:** Всплывающие подсказки с детализацией остатков товара по городам (Москва, Оренбург, Санкт-Петербург) на базе **Tippy.js** и **Popper.js**.
- **Форма обратной связи:** Клиентская валидация полей (имя, email, чекбокс согласия) через **JustValidate** и асинхронная отправка данных (`FormData` + `fetch`) с выводом модального окна статуса.
- **UI-компоненты:** Выпадающее меню категорий, выбор города, FAQ-аккордеон.

## 🛠 Технологический стек

- **HTML5** (семантическая разметка, БЭМ-нейминг)
- **CSS3 / SCSS** (адаптивная сетка Flexbox / Grid)
- **JavaScript (ES6+):** ES-модули, DOM API, Fetch API, Async/Await, LocalStorage, методы массивов (`filter`, `some`, `sort`, `slice`, `forEach`).
- **Библиотеки:**
  - [Swiper.js](https://swiperjs.com/) — слайдер товаров дня
  - [JustValidate](https://just-validate.dev/) — валидация формы
  - [Tippy.js](https://atomiks.github.io/tippyjs/) + Popper — тултипы наличия товаров

## 📂 Архитектура проекта

```text
├── css/                  # Скомпилированные стили
├── data/
│   └── data.json         # База данных товаров (JSON)
├── fonts/                # Локальные шрифты (NotoSans)
├── images/               # Изображения товаров и SVG-спрайт
├── js/
│   ├── components/       # ES-модули по компонентам:
│   │   ├── accordion.js  # Логика FAQ-аккордеона
│   │   ├── basket.js     # Корзина и работа с localStorage
│   │   ├── form.js       # Валидация, отправка формы и модальное окно
│   │   ├── location.js   # Выбор города в шапке
│   │   ├── menu.js       # Бургер-меню категорий
│   │   ├── products.js   # Каталог, фильтрация, сортировка, пагинация
│   │   ├── slider.js     # Слайдер «Товары дня»
│   │   └── utils.js      # Общие утилиты (форматирование цен, инициализация Tippy)
│   ├── vendor/           # Сторонние библиотеки (Swiper, JustValidate, Tippy, Popper)
│   └── main.js           # Точка входа (инициализация модулей)
├── scss/                 # Исходники стилей (SCSS)
└── index.html            # Главная страница каталога
```
